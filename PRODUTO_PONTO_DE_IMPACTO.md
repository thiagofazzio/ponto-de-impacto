# Diagnóstico Ponto de Impacto - TFAZZIO

## 📌 Visão Geral do Produto

O **Ponto de Impacto** é um diagnóstico estratégico para PMEs que identifica o gargalo principal que está travando o crescimento do negócio. Em menos de 10 minutos, o método TFAZZIO cruza dados oficiais do CNPJ com a realidade da operação para gerar um relatório completo e acionável.

**URL:** https://ponto.tfazzio.com.br

---

## 🎯 Problema que Resolve

Empresários de PMEs frequentemente enfrentam:

- **Falta de clareza** sobre o que realmente está impedindo o crescimento
- **Dificuldade em priorizar** entre tantas demandas do dia a dia
- **Decisões baseadas em intuição** em vez de dados concretos
- **Desperdício de energia** em áreas que não geram impacto real
- **Falta de um plano estruturado** para os próximos 90 dias

O Ponto de Impacto resolve isso entregando um diagnóstico preciso, com dados reais e recomendações práticas.

---

## 👥 Público-Alvo

- **Pequenas e Médias Empresas (PMEs)** de todos os setores
- **Empresários e sócios-fundadores** que querem crescer com mais clareza
- **Negócios com faturamento entre R$ 50 mil e R$ 5 milhões/mês**
- **Empresas que já têm operação rodando** mas sentem que algo está travando

## ⚙️ Como Funciona

### 1. Wizard Rápido (menos de 10 minutos)
O usuário responde perguntas objetivas sobre:
- Modelo de negócio e setor
- Objetivos e desafios
- Dados financeiros (faturamento, custos)
- Estrutura comercial
- Autoavaliação de 6 áreas da empresa

### 2. Coleta de Dados Automática
O sistema busca automaticamente:
- **Dados do CNPJ** via BrasilAPI
- **Reputação Online** via Google Places API
- **Menções na Imprensa** via SerpAPI

### 3. Geração do Relatório
O motor TFAZZIO processa os dados e gera:
- **Índice de Clareza** (0 a 100)
- **Gargalo Principal** identificado
- **Análise das 6 Áreas** com notas e status
- **Ponto de Equilíbrio (Break-Even)** calculado
- **Plano de Ação de 90 Dias** com tarefas práticas
- **Recomendações Estratégicas** priorizadas

### 4. Entrega
- **Dashboard Online** interativo com gráficos
- **PDF Profissional** para download e compartilhamento

## 📊 Entregáveis do Diagnóstico

| Entregável | Descrição |
|------------|-----------|
| **Índice de Clareza** | Score de 0 a 100 que mede a maturidade da gestão |
| **Gargalo Principal** | A área que mais está travando o crescimento |
| **Gargalo Secundário** | Segunda maior oportunidade de melhoria |
| **Análise das 6 Áreas** | Financeiro, Comercial, Operação, Gestão, Pessoas, Estratégia |
| **Ponto de Equilíbrio** | Faturamento mínimo necessário para cobrir custos |
| **Margem de Contribuição** | Percentual que sobra após custos variáveis |
| **Lucro Líquido Estimado** | Projeção de lucro com os dados informados |
| **Plano de Ação 90 Dias** | 3 fases com tarefas práticas e prioridades |
| **Recomendações Estratégicas** | 4 ações prioritárias para o negócio |
| **Evidências Coletadas** | Dados do CNPJ, Google Places e Imprensa |
| **Dashboard Online** | Visualização interativa com gráficos |
| **PDF Profissional** | Relatório completo para download |
